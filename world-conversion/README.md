# World conversion / 存档转换专区

This directory keeps the special conversion builds, World cleaner and their instructions together, independently of normal gameplay releases.

本目录独立保存存档转换专用版本、World cleaner 和操作说明，方便玩家随时查找。

| Version / 版本 | Downloads and instructions / 下载与说明 |
| --- | --- |
| 0.2.9-beta | [Open conversion package / 打开转换专区](./0.2.9-beta/) |

**Back up your world before conversion. / 转换前务必备份存档。**

The integrated transition mod preserves blocks when cleaning connections. World cleaner is a separate fallback that removes legacy components and related constraint providers. Read the instructions before choosing a method.

过渡整合版清连接时保留方块；World cleaner 是删除旧组件及相关约束提供者的后备方案。请选择适合的方式，并始终保留原档。

For maintainers: retain this directory when publishing future normal releases. Add future conversion versions in separate version folders; do not replace the archived builds.
维护约定：后续普通版本发布时保留本专区。新的转换版本使用新的版本目录，不覆盖已归档版本。
