# 物理消防水带：头对头版本

## 方块与操作

- 2026-10-26：统一入口为 `physical_fire_hose`，默认截面 8×8。普通扳手右键按 8→6→4→8 切换尺寸，不改变朝向；连接后同步两端尺寸，另一端未加载时暂不切换。
- 旧 `physical_fire_hose_4/6/8` ID 保留用于已有存档，从创造栏和 JEI 隐藏；拆回时获得统一物品。
- 连续放置两个水带头，第二个沿用已选择端点的尺寸，放置时自动连接。生存模式消耗两个水带头，无需第三个连接物品。
- 手持物理水带，依次右键两个已放置、空闲且同尺寸的水带头，也可连接。潜行右键水带头取消选择；剪刀可从任一端断开。
- 拆除水带头沿用普通消防水带的方块流程：生存模式破坏掉落一个物理水带，潜行扳手拆回一个；同时删除连接的水带体，另一端保留并解除连接。创造模式沿用 Create 的不返还规则。
- 剪刀右键任一水带头只断开水带体，保留两端，不额外返还物品、不消耗剪刀耐久；成功时播放剪切音效。主手剪刀也可沿用 rope 的瞄准交互剪断水带体；扳手不能单独剪断水带体。客户端优先处理水带头本身的方块操作，避免原生 rope 的潜行扳手动作抢先剪断连接。
- 连接距离同时受本模组的水带长度配置和 Simulated 的绳索最大范围约束。拒绝跨维度、不同尺寸、重复占用和失效的端点选择。
- 本版提供创造栏物品；尚未添加独立合成配方和物理水带绞盘。

## 物理与流体

使用 Simulated 的 `RopeStrandHolderBehavior` 和 `ServerRopeStrand`，保留其碰撞、约束、分节、存档、网络同步和结构装配回调。完整物理段长度仍为 1 格；原生首段可以是小数长度。中间没有节点方块，也不绘制原来的绳结模型。

三个截面是视觉规格。碰撞半径和质量等参数仍沿用原生 rope，本版不因截面变化而修改这些物理参数。普通 Create contraption 不允许搬运新水带头；Sable 结构使用原生 rope 装配回调更新约束端点和流体连接位置。

流体复用现有消防水带的共享缓冲和 Create 压力行为。只有原生物理连接有效且两端已加载时才参与传输。未加载的连接保留存档；切断或拆除后的连接停止传输。不同尺寸暂不区分流量。

普通消防水带连接器、支架路由和普通绳索物品不能接管物理水带。剪断不返还 Simulated 的绳索物品，两个水带头仍可独立拆回。

## 模型与贴图

源模型：`D:/CreateAdd/assets/Firefighting/fire_hose/phys_hose/phy_hose_{4,6,8}.json`。

已导入每种尺寸的 A、mid、B 三部分。水带头采用同目录下新提供的 `fire_hose_hand_{4,6,8}.json`，保留源模型元素和 UV。模型位于 `assets/createfirefightingadd/models/block/physical_fire_hose/`。

染色沿用消防水带外观注册表：白色染料恢复默认，黑色染料切换黑色，幻翼膜切换透明。两端外观同步；模型按原有 UV 替换头部和管体贴图，也支持注册表中的自定义外观。连接已有染色端点时沿用普通消防水带的外观选择规则。

- mid 保持原模型中间 12px 的长度，随物理段平移和旋转。
- 相邻完整段共线时使用 A/B 的 2px 肩部；弯曲时不绘制这两块，而从两个 mid 端面绘制动态过渡段。
- 首段不足 16px 时裁剪 mid，保留像素密度，不把 12px 模型压缩到短段里。
- 仅在两个水带头出口与各自最近的 mid 端面之间补绘过渡段。首尾及中间节段保持原有位置、朝向和段间连接，不平移整节水带，也不额外延长出口直线段。
- 头部按空间距离匹配渲染链条的首尾，不依赖点列表的正反顺序。头部接片直接衔接两个方形端面的对应边角，避免短间隙中的样条回折。
- 动态接片的四个表面分别按两条纵边的平均长度累计 UV，再按整数边界重复／裁剪；弯曲外侧不再沿用更短的中心线长度。固定 mid 模型及物理点位不变。
- 帧方向沿各段传递，减少水带截面因方向变化而突然翻转。上述处理不移动物理节点，也不缩短碰撞段。

所有消防水带的动态绘制现在按实际绘制路径累计长度：每 1 格重复一次贴图，跨整数边界时切分四边形，末段使用相应的贴图片段。去除了顶点 UV 单独取余和按端点距离缩放 UV 的处理。有效贴图区域为 PNG 的左侧 8×16；截面 4/6/8 分别使用 U=2..6、1..7、0..8 像素。

## 兼容边界

新增独立能力 `PHYSICAL_HOSE`，要求 Sable `[2.0.0,3.0.0)` 和 Simulated `[1.3.0,1.4.0)`，不依赖 Synaxis。加载时探测原生创建/销毁方法和适配器。

无依赖或旧版依赖时仍注册方块、模型和可保留数据的方块实体，但隐藏物品、禁止交互和流体传输；原生 `OwnStrand`、`HasRopeAttached`、`Strand` 数据原样保留。原有消防水带仍可使用。

- `checkHoseTexture`：整数边界、负起始相位、短段、长段、中心裁剪、直角及反向段的截面方向。
- 同一检查还覆盖渲染点序反向时的头部匹配、三种宽度与六方向的实际输出端面顶点、短弯接片表面像素密度和长接片的分片输出，全程不启动游戏。
- `PhysicalHoseGameTests`：两个物品连续放置、原生连接与拆除、卸载后恢复、原生装配回调、抽水及水量守恒、禁用时的数据保留。
- `PhysicalHoseClientChecks`：真实模型烘焙与贴图加载、实际顶点输出、三种尺寸的原生服务端到客户端点位同步，以及真实渲染过程。
- `runCompatibilitySmoke -PcompatibilitySmoke -PcompatibilityProfile=<profile>`：按独立测试目录加载依赖组合。
- `runCompatibilityClientSmoke -PcompatibilitySmoke -PcompatibilityProfile=<profile>`：创建独立临时世界，完成检查后退出。

测试世界与日志保存在 `build/compatibility-smoke-*`；不使用或改写玩家存档。
