# 消防拉梯重写规划

> 状态：第一版重写实现已开始落地；本文档仍作为后续修正的基准。
>
> 重要：现有 `content/blocks/extension_ladder/` 实现只作为历史参考，不作为新实现的基础。后续重写应先建立新的数据模型和坐标变换，再替换旧代码。

## 1. 目标

消防拉梯使用一个地面定位点和玩家水平朝向完成放置。拉梯被模拟为一个可以绕定位面旋转的长方形平面，支持普通世界和 Sable 子结构，并在支撑丢失时以分阶段、低 TPS 负担的方式继续倒下。

第一阶段攀爬只提供动态攀爬交互，不实现任意位置的完整实体站立碰撞。

## 2. 放置交互

1. 玩家手持拉梯，对准一个方块的顶部 `UP` 面。
2. 第一次右键即完成唯一定位点选择，不再选择第二个点。
3. 定位点 `A` 是第一个地面定位面的面中心，不是射线命中点，也不是方块几何原点。
4. 控制方块只放在第一个定位面对应的相邻可替换方块位置；不在其它位置创建控制方块。
5. 玩家水平视线决定倒下方向，忽略视线 Y 分量。
6. 选点标记只显示被选择的面，不能显示整个方块。

```text
fallDirection = normalize(playerLook.x, 0, playerLook.z)
```

## 3. 模型坐标和固定校准

模型展示状态显示：`move` 部分位于 north 侧，`nomove` 固定部分位于 south 侧。

从原始模型结构得到的局部坐标约定：

| 局部轴 | 含义 |
| --- | --- |
| `+Y` | 拉梯长向/模型展开方向 |
| `X` | 拉梯短边宽度方向 |
| `+Z` | `nomove` 固定侧，靠 south |
| `-Z` | `onlymove` 可动侧，靠 north |

模型的展示基准方向存在固定的 yaw 校准偏移：

```text
modelYaw = playerYaw + 180 degrees
```

这个 `180 degrees` 是模型朝向校准，不是物理倒向反转，不得通过反转玩家视线向量代替。

旋转流程：

1. 以模型展示方向为基准计算玩家水平 yaw。
2. 加上固定 `MODEL_YAW_OFFSET = 180 degrees`。
3. 以校准后的短边轴进行 pitch 倾倒。
4. move、nomove、绳索和碰撞使用同一套变换。

模型原始 JSON 的坐标零点不是拉梯物理旋转中心。必须单独定义逻辑参考点：

```text
moveOffset = 0
```

表示模型处于导出文件的默认收起状态，不代表模型自身坐标的 `(0, 0, 0)`。

## 4. 展开长度和动画

当前确认的可动部分最大位移为：

```text
MAX_MOVE_OFFSET_PIXELS = 39
```

定义：

```text
moveOffset = 0px    默认收起参考状态
moveOffset = 39px   最大展开状态
```

不得再使用旧的 43px 作为 move 的可见位移。

`nomove` 保持在定位参考点侧，`onlymove` 只沿模型定义的展开方向移动。展开位移必须是独立动画变量，不得把模型局部坐标零点、总长度或绳索定位点当成位移值。

绳索渲染要求：

- `rope` 模型是宽度 1px、厚度 0 的平面，不是 1px 立方柱。
- `rope` 模型的局部起点必须位于 `(0, 0, 0)`，renderer 才能让绳索端点严格贴合指定定位点。
- 动态绳索端点为 `onlymove` 中 `tip` 体素旋转后的南面中心到 `nomove` 中 `point1` 的 cube 中心。
- 固定绳索端点为 `point1` cube 中心到 `point2` cube 中心。
- 下垂绳索从 `point2` cube 中心向下 30px。

放置动画：

```text
DROP
  -> EXTEND (0px -> 39px)
  -> SEARCH_SUPPORT
  -> TILT_TO_SUPPORT
  -> SUPPORTED
```

下落动效：初始离定位面 4px，用 2 tick 快速落到定位面；落地后不再上弹，而是围绕脚点做 5 tick 的短促左右衰减晃动，让玩家感受到梯子被放下并放稳。展开动画结束后才开始 pitch 倾倒。

## 5. 平面几何

拉梯物理模型是一个长方形平面，旋转中心为 `A`。

1. yaw 只决定水平朝向。
2. pitch 只决定从竖直状态向 `fallDirection` 倾倒的角度。
3. pitch 绕 yaw 校准后的短边轴旋转。
4. 短边始终保持水平，并经过第一个定位面。
5. 不允许额外 roll。
6. 不允许将拉梯长度轴整体取反来修复 move/nomove 朝向。

逻辑变换应明确分成：

```text
modelReference -> yaw calibration -> pitch rotation -> world pivot A
```

## 6. 扇形柱体支撑搜索

拉梯从竖直状态开始，沿当前 pitch 方向搜索可靠支撑。搜索对象是整个拉梯长方形平面在 pitch 变化过程中扫过的扇形柱体，而不是单条中心线。

每个 pitch 候选需要考虑：

- 两条长边
- 短边
- 拉梯宽度
- 拉梯厚度
- 当前 pitch 到下一 pitch 的扫掠空间

可靠支撑需要满足：

- 碰撞方块不属于第一个定位方块或控制方块。
- 碰撞位于拉梯外端或有效受力区域。
- 碰撞面能够提供稳定接触。
- 不是只擦过方块角点或无效边缘。

### 性能策略

- 初始搜索和倒塌搜索都分多个 tick 执行。
- 保存 `searchPitch`、搜索区间和搜索版本，不重复从头计算。
- 粗略 AABB 先排除空区域。
- 命中候选区间后再使用细采样/二分细分。
- 每个拉梯有单独扫描预算。
- 所有拉梯共享本 tick 的总扫描预算。
- 不强制加载未加载区块。
- 缓存可复用的碰撞形状和最近搜索结果。
- 稳定状态只检查当前支撑接触，不完整扫描扇形柱体。

扫描预算不足时只延迟搜索完成时间，不允许阻塞主线程或造成 TPS 峰值。

## 7. 支撑丢失

### 第一个定位方块

第一个定位方块消失、被破坏或从所属 Sable 子结构中移除时：

- 立即破坏拉梯控制方块。
- 拉梯掉落为物品。
- 不向下寻找替代定位点。

### 当前支撑方块

当前支撑方块失效包括：

- 方块被破坏或移除。
- Sable 子结构移动后支撑不再与拉梯接触。
- 没有方块更新，但当前碰撞形状已离开接触区域。

失效后：

1. 保持当前 yaw。
2. 保持当前 pitch。
3. 从当前 pitch 继续向后搜索。
4. 找到新可靠支撑后播放旧 pitch 到新 pitch 的倒塌动画。
5. 找不到支撑时进入失稳/掉落终态，不能回到稳定态后再次循环搜索。

## 8. Sable 兼容

支撑引用不能只保存普通世界坐标。需要保存：

```text
BlockPos
SubLevel UUID
所在 Level
局部坐标
```

统一碰撞接口以世界空间几何为输入，底层根据空间类型查询碰撞。

必须覆盖：

```text
世界-世界
Sable-Sable
Sable-世界
世界-Sable
```

### 位姿变化

Sable 支撑不依赖方块更新事件。稳定状态下每次结构位姿变化只执行当前接触区域的轻量检查：

```text
位姿变化
  -> 更新支撑方块世界位置和碰撞形状
  -> 仍接触：保持稳定
  -> 不再接触：启动从当前 pitch 开始的搜索
```

如果第一个定位点在 Sable 中，拉梯跟随该子结构；只有该局部定位方块真正消失才立即掉落。

## 9. 第一阶段攀爬交互

暂不实现整个倾斜长方形面的任意位置站立碰撞。

第一阶段实现：

- 玩家接近拉梯后进入动态攀爬范围。
- `W/S` 沿拉梯长轴上下移动。
- 玩家可以在任意高度停留。
- 跳跃、潜行或离开范围时退出攀爬。
- 不锁定玩家世界坐标。
- 拉梯移动或倒塌时不强制拖拽玩家。
- 普通世界和 Sable 使用同一套世界空间梯面投影。

不生成大量隐形方块，不增加大量 blockstates，不依赖 Sable 才能运行。

## 10. 新实现结构

旧拉梯实现废弃后，建议建立以下边界：

```text
ExtensionLadderBlockEntity
    状态、定位点、动画和支撑引用

ExtensionLadderGeometry
    参考点、yaw、pitch、模型变换和扫掠体

ExtensionLadderSearchTask
    分 tick 的预算化 pitch 搜索

ExtensionLadderSupportRef
    世界/Sable 方块引用和位姿快照

ExtensionLadderCollisionAccess
    普通世界和 Sable 碰撞适配

ExtensionLadderRenderer
    只负责模型、move、绳索和动画插值

ExtensionLadderClimbingController
    第一阶段攀爬输入和梯面投影
```

## 11. 验收条件

重写前后必须验证：

1. 面向 north 放置时先应用 `yaw + 180 degrees`，模型 move/nomove 朝向正确。
2. 面向 south、east、west 时具有一致的模型语义。
3. 第一个定位面是唯一旋转中心和控制位置。
4. 选点标记只显示顶部面薄框。
5. move 从 0px 展开到 39px，不超过 39px。
6. 展开动画完整播放。
7. pitch 倾倒不会改变 yaw 或短边水平状态。
8. 无支撑时不会反复立起和倒下。
9. 第一个定位方块消失时立即掉落。
10. Sable 结构只移动但无方块更新时，支撑失效仍能被检测。
11. 世界-世界、Sable-Sable、Sable-世界、世界-Sable 均能进行测试。
12. `gradlew build`、资源 JSON 校验和游戏内截图测试通过。

- 不继续在废弃实现上追加补丁。
- 未经用户确认，不修改版本号、`tempbackup`、Git 分支或远程仓库。
