# 物理水带固定支架

2026-10-26：实现方案 1。使用 Create 原有金属／木质支架物品，将选中的整节水带固定到已有表面；只检查长度是否可达，不检查绕障路径。

## 操作

1. 手持支架，仅玩家指向的自由水带节段显示绿色中心选择框，尺寸对应 8×8×8、6×6×6、4×4×4 px，随节段旋转。不显示其他节段的选择框。
2. 右键中心框选择节段。选择记录水带 UUID、持有端点及节段位置，不保存一个会随运动失效的世界坐标。
3. 指向已有表面，从两侧端口分别绘制单条直线到目标中心。长度足够为原水带提示绿色，某侧不足只将该侧标红；两侧不足则都标红。目标中心使用蛙港选点同款零尺寸包围盒、0.2 线宽和关闭线条明暗的绿色加粗点，不绘制管体方盒预览。
4. 右键放置，服务器重新检查长度、占用和原有放置权限。失败不消费支架，保留选择；潜行右键取消选择。
5. 潜行扳手拆除支架，生存模式返还支架，固定节段恢复自由运动。不会增减水带长度，也不额外返还水带。

两侧预览连线共用目标点逐帧插值后的中心位置，跟随 Create 原有追踪动画移动并一起淡出。长度判定仍以实际放置目标为准。

选点仅在支架保持于原手、原快捷栏槽位时有效。切换手持物品、交换主副手或丢弃支架会取消选点；丢弃单个支架时，手中剩余支架也会清除选点记录，重新拿回后需要重新选择。

目标节段的初始方向由放置面和玩家视线决定，放置后沿用支架的扳手角度设置；调整后两侧长度不足时保留原角度。

选中节段不再显示文字提示。手持物理水带选中端口时，使用原消防水带风格的绿色端口线框、目标线框和连线粒子；取消及失败提示保留。

## 长度和物理

固定节段保留原有长度：普通节段为 1 格，小数首节使用原生静止长度。中心位于支架方块中心，两个固定端位于中心沿水带轴向的 ±半节长度处。

分别比较左侧最近固定端到目标左出线口、目标右出线口到右侧最近固定端的直线距离。每侧可用长度由原生静止长度及选中的材料区间决定，不计入求解中的临时拉伸，也不能借用另一侧的余量。

2026-10-27：每侧判定额外允许 1 格距离宽容。预览、服务端放置及支架角度调整使用相同阈值；宽容不增加水带的实际长度，也不写入材料长度分配。

支持同一条水带上的多个固定节段。原生点列表的槽位保持不变，固定节段之间的自由区间分别使用原生绳索求解。抬高某一节后，两侧按各自保留的长度自然形成新的悬垂区间，不生成额外长度。

拆除支架时从当前姿态重建相连自由区间；移除最后一个支架后恢复单一原生求解句柄。当前物理水带没有绞盘收放，因此绑定节段索引对应固定的材料区间；未来加入收放时需一并适配该映射。

## 方块、显示和生命周期

- 复用 hose_bracket 方块及其回收交互，物理模式保存原水带绑定；不创建新的流体端点。
- 固定管体仍由物理水带渲染器绘制，支架渲染器只画夹具，避免重复管体。固定节段的截面姿态对齐夹具；其余节段保持原渲染、纹理平铺和连接过渡。
- 固定段退出绳索自由碰撞，改用支架方块包含整段的碰撞形状。自由段仍沿用原生 rope 参数。
- 宽度和染色继续跟随原水带。剪断水带或删除端点时清理绑定支架，并按原支架掉落规则回收。
- 绑定随端点和支架保存；Sable 引用使用现有位置映射及装配回调。支架位于已有 Sable 结构上时，两个固定端使用结构局部坐标。
- 物理支架与物理水带头一样，不接入普通 Create contraption 搬运。普通消防水带支架的原有搬运行为保留。
- 流体铰链等不允许普通水带连接的端点不再进入普通支架候选判定。物理水带通过独立的中心选择流程接入。
