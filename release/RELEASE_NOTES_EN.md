# 0.2.7-beta / 0.2.8-beta Release Notes

Firefighting and Powertrain may become two separate mods in a future version. Please back up your worlds before updating.

Neither version includes this split. Both are complete, usable versions with the same blocks, items, and gameplay features.

| Version | Difference |
| --- | --- |
| 0.2.7-beta | Does not display the split-plan reminder. |
| 0.2.8-beta | Displays the split-plan and backup reminder once in chat each time you enter a world or join a server. |

Apart from the version number and this reminder, the two versions have the same content. Choose whichever you prefer. Install only one jar at a time; do not install both together.

The chat reminder in 0.2.8-beta reads:

> [Create Firefighting Add] Firefighting and Powertrain may become separate mods in a future version. Please back up your worlds before updating.
